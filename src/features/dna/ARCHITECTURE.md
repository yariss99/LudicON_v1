# Mission 08 — Pedagogical DNA

## Intent

Learn how teachers teach. Remember professional style patterns.

**Never** judge. **Never** score. **Never** rank.

## Observe

- Teaching methods  
- Lesson structure  
- Assessment preferences  
- Digital tools  
- Learning activities  
- Timing  

## Build

A **Teacher Pedagogical DNA** profile — professional style, not personality.

Presence is qualitative only: `emerging` · `familiar` · `signature`.

## Use

Adapt future suggestions to teacher style. Teacher always controls.

## Show

Visual Teaching Profile — simple, beautiful, positive (`/dna`).

## Evolution

Year-by-year narrative of how practice changed.

## Export

Markdown (portfolio) and JSON downloads for reflection.

## Code

- Types: `src/types/pedagogicalDna.ts`
- Engine: `src/engines/dna/`
- Service: `src/services/pedagogicalDnaService.ts`
- UI: `src/features/dna/`

Sources: Classroom Intelligence versions + class-level feedback only.

# Mission 09 — Teacher Confidence Engine

## Intent

Help teachers feel prepared.

**Evaluate learning experiences. Never evaluate teachers.**

## Confidence Panel

| Signal | Meaning |
|--------|---------|
| Lesson readiness | Core pieces present & ready |
| Estimated timing | Fit vs available minutes |
| Required resources | Materials teachability |
| Assessment coverage | Formative / check moment |
| Differentiation | Multiple learner paths |
| Reflection | Closing ritual |

## Confidence score

Represents **lesson readiness** only. Every dimension score includes a plain-language explanation.

## Improvements

Small, practical, **one-click** actions via `studioService.applyConfidenceAction`.

## Route / surface

Living Workspace right panel (`/studio/:projectId`).

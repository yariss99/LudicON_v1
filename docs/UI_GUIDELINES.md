# Golden Principles

1. Simplicity before complexity.

2. Save teachers time.

3. AI recommends. Teachers decide.

4. One primary action per screen.

5. Consistency is more important than originality.
# 1. Design Philosophy

LUDI ON is an AI-powered platform designed for primary school teachers.

The interface must always feel:

- Clear
- Calm
- Professional
- Trustworthy
- Efficient

The primary objective of every screen is to help teachers create high-quality educational activities with the minimum number of interactions.

Every design decision should reduce cognitive load, increase clarity, and save time.

# PRIMA Product DNA

Philosophical foundation: [`DOCUMENT-000 — The PRIMA Manifesto`](./DOCUMENT-000_PRIMA_MANIFESTO.md).

PRIMA is an **AI-Native Pedagogical Design Studio**.

It is not an LMS. It is not a lesson generator. It is not another educational platform.

## Mission

Help teachers transform educational ideas into complete learning experiences with the least possible effort and the highest pedagogical quality.

## Core idea

Everything is a **Living Workspace** — an evolving educational project that grows, remembers, connects resources, and receives AI suggestions.

## Principles

1. Never ask the teacher to navigate — bring the work to the teacher.
2. Reduce cognitive load — one question per screen.
3. Every click must have value.
4. AI is a pedagogical colleague — proposes; teachers decide.
5. Teachers create learning experiences — documents are artifacts.
6. Everything starts with intention.

## Feature rule

Build only what saves time, improves educational quality, or reduces stress.

## Product feeling

When teachers close PRIMA they should feel more prepared than when they opened it. That feeling is the product.

# LUDI ON — Product Roadmap

> **Shipping authority:** [`PRIMA_MVP_ROADMAP.md`](./PRIMA_MVP_ROADMAP.md) defines Versions 0.1 / 0.5 / 1.0 / 2.0 and prioritization. This document is retained as historical sequencing context; **MVP Roadmap prevails on cuts and scope conflicts**.

---

## North Star

A teacher creates a complete, high-quality educational activity in under 60 seconds *(configuration)* — with full instructional design in under 5 minutes *(first session)*.

Every version must move the product closer to this goal.

---

## Version 0.1 — Foundation *(In Progress)*

**Objectives**

- Project architecture and documentation system
- Design system foundation
- Dashboard creative workspace
- PRIMA welcome experience
- GitHub repository and development workflow

**Exit criteria**

- Documentation architecture complete
- Dashboard shippable UI (Romanian)
- PRIMA entry point from Lecție builder
- Build passes; no TypeScript errors

---

## Version 0.2 — PRIMA Conversation (Discovery)

**Objectives**

- PRIMA conversation Stages 0–7 (Welcome through Preferences)
- PRIMA Session Model (data contract)
- Inference layer v1 (profile + conversation)
- No visible steps or forms

**Exit criteria**

- Teacher completes discovery without questionnaire feeling
- Session model populated from conversation

---

## Version 0.3 — Instructional Blueprint

**Objectives**

- PRIMA thinking + blueprint presentation (Stages 8–10)
- Instructional Blueprint schema v1
- Teacher review and approval gate
- Blueprint editing

**Exit criteria**

- Approved blueprint required before generation

---

## Version 0.4 — Generation & Export

**Objectives**

- AI generation pipeline (Stage 11)
- Editing experience (Stage 12)
- Export and library save (Stage 13)
- First activity type end-to-end: **Lecție**

**Exit criteria**

- Teacher exports PDF/PPTX from approved blueprint

---

## Version 0.5 — Activity Builder Expansion

**Objectives**

- Additional builders: Fișă, Joc, Evaluare, Poveste, Prezentare, Misiune
- Builder-specific PRIMA conversation adaptations
- Personal Library v1

---

## Version 0.6 — PRIMA Memory

**Objectives**

- Cross-session teacher memory
- Compressed discovery for returning users
- Dashboard recommendations from memory

---

## Version 0.7 — Community

**Objectives**

- Share activities, templates, ratings
- Marketplace exploration

---

## Version 1.0 — Public Release

**Goals**

- Stable, fast, reliable, beautiful, AI-first
- Romanian schools pilot-ready

---

## Development Principles

Every version must:

- Pass build
- Remain responsive
- Respect design and product documentation
- Improve teacher productivity without sacrificing pedagogy
- Document before implementing major features

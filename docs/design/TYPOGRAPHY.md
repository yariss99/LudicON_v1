# LUDI ON — Typography

---

## Typeface

**Primary:** Inter (400, 500, 600, 700)

Loaded via Google Fonts. Applied globally on `body`.

Fallback: `ui-sans-serif, system-ui, sans-serif`

---

## Scale — Dashboard

| Role | Size | Weight | Line height |
|------|------|--------|-------------|
| Hero title | 48px (desktop) | 700 | 1.05 |
| Hero mission | 20–22px | 400 | 1.6 |
| Action title | 20–24px | 700 | 1.2 |
| Helper text | 16–18px | 400 | 1.6 |
| Builder card title | 22px | 600 | tight |
| Builder description | 16px | 400 | 1.6 |
| Section header (subtle) | 18px | 500 | 1.3 |
| Body | 16px | 400 | 1.6 |
| Caption | 13–14px | 400–500 | 1.4 |

---

## Scale — PRIMA

| Role | Size | Weight |
|------|------|--------|
| PRIMA wordmark | 40–48px | 700 |
| Welcome title | 24–28px | 600 |
| Body message | 16–17px | 400 |
| Checklist item | 15px | 400 |
| CTA button | 17px | 600 |

## Color Pairing

| Text | Color |
|------|-------|
| Primary headings | `#0F172A` (slate-900) |
| Body | `#64748B` (slate-500) |
| Emphasis | `#0F172A` semibold |
| Links | `#2563EB` (blue-600) |
| PRIMA accent labels | `#2563EB` / `#4F46E5` |

---

## Rules

- No more than 3 sizes on one screen
- Prefer sentence case in Romanian UI
- Avoid ALL CAPS except small labels (tracking-wider, 12px max)
- Descriptions never truncated on builder cards

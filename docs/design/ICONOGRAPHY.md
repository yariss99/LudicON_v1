# LUDI ON — Iconography

---

## Icon Library

**Primary:** [Lucide React](https://lucide.dev) — consistent stroke icons.

**Stroke weight:** 1.5 default; 1.25 for large display icons.

---

## Sizes

| Context | Size |
|---------|------|
| Header controls | 18–20px |
| Builder card icon | 34px in 60px circle |
| Checklist check | 11–12px |
| Resource row | 20px |

---

---

## Emoji Policy

| Allowed | Avoid |
|---------|-------|
| Welcome copy (👋, ✨) sparingly | Emoji as primary navigation icons |
| Marketing hero accents | Multiple emoji per line |
| — | Childish overload in PRIMA conversation |

PRIMA conversational UI prefers **Lucide + typography** over emoji for professionalism.

---

## Logo Mark

Sparkles icon (`Sparkles`) in gradient rounded square — LUDI ON header.

PRIMA wordmark is **text-only** in welcome (no robot avatar v1).
